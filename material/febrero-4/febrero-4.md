# Activity Browser (AB)

_Cuidado_ A la fecha (Febrero 2025) el **Activity Browser** no es compatible con Brightway25.

La sesión de hoy se divide en 2: Primero pasos y uso de premise.

## Primeros psaos

El objetivo de la sesión, es familiarizarse con el Activity Browser.
Vamos a seguir las siguientes etapas:

+ Crear un ambiente python para AB con la ayuda del [archivo de ambiente ya preparado](/material/environments/environment_ab.yaml)
+ Restaurar un proyecto que incluya una base de datos background
+ Demostrar el uso de jupyter y AB al mismo tiempo
+ Reproducir el inventario de la bicicleta en el proyecto restaurado
+ Hacer un escenario con una bicicleta de aluminio y una de fibra de carbono
+ parametrizar el peso de la bicicleta (agregar una variable `bike_size` que multiplica la cantidad de material (Aluminio/Fibra de Carbono)
+ Agregar Electricidad a nuestro inventario
